# Tic Tac Toe in Python

A console-based Tic Tac Toe game with HTML output visualization.

## Features
- Computer plays with 'X' (random moves)
- Human player uses 'O'
- Computer always starts in the center
- Win/tie detection
- Generates HTML visualization of the board
